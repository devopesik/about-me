# Одностраничный сайт-резюме Михаила Лазарева

## Структура

- `index.html` — разметка сайта.
- `styles.css` — оформление и адаптивность.
- `script.js` — мобильное меню и анимации появления блоков.
- `resume.pdf` — исходный текст резюме.

## Особенности

- Адаптивный дизайн с карточками опыта, навыков и модальными окнами.
- Переключение между светлой и тёмной темами (по умолчанию активна светлая).
- Ленивая анимация появления блоков и мобильное навигационное меню.
- Интерактивные карточки навыков с описанием выполненных задач.
